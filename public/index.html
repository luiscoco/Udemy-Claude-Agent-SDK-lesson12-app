        Lesson scope

        The four scenarios execute setModel, setPermissionMode, applyFlagSettings and both supported updateSettings targets. setModel() with no argument, Python controls, other settings keys and cache-cost calculations remain reference material. No cwd setter exists: use a new query to change project. A model switch can require processing the conversation at the new model’s rates; this lab does not isolate or benchmark cache misses. Cost fields are estimates and cumulative within a live query, so do not add its turn totals.
